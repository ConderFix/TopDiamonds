Плагин для создания топа игроков по количеству вложенных алмазов. Плагин позволяет игрокам добавлять алмазы, которые они держат в руке, и просматривать текущий топ. 

## Команды

- `/test additem` — добавляет алмазы в топ. Количество алмазов определяется количеством предметов в руке.
- `/test top` — отображает текущий топ игроков по количеству вложенных алмазов.

## Пример использования

1. Игрок держит в руке 5 алмазов и вводит команду `/test additem`. 
  Результат: В топ добавляется новый пользователь со счетом 5.
2. Игрок вводит команду `/test top` 
  Результат: Игроку показывается топ по алмамзам
